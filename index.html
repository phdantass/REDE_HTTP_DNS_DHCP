Projeto de Infraestrutura de Rede Local

Documentação da Topologia no Cisco Packet Tracer

Status: Ativo / Configurado

Visão Geral da Topologia

O projeto consiste em uma arquitetura de rede local (LAN) conectada à WAN (Internet / Provedor) por meio de um roteador de borda. A rede interna conta com serviços dedicados de infraestrutura (DHCP, HTTP e DNS) e um pool de endereçamento configurado para as estações de trabalho.

Mapeamento de Dispositivos e Endereçamento

Dispositivo Interface Endereço IP Função / Descrição
Cloud0 — 100.10.2.190/10 Simulação do IP do Fornecedor / WAN
Router0 (1941) g0/1 192.168.0.1 Gateway Padrão da Rede LAN
Server DHCP f0/5 192.168.0.10 Servidor de Atribuição Dinâmica de IPs
Server HTTP f0/6 192.168.0.11 Servidor Web da Redes Interna / Intranet
Server DNS f0/7 192.168.0.12 Resolução de Nomes da Rede
PCs (PC0 a PC3) f0/1 a f0/4 A partir de 192.168.0.100 Estações de trabalho do usuário via DHCP

Serviços e Regras de Negócio

  • Acesso WAN / NAT: Conexão externa provida via interface g0/0 do roteador conectada à nuvem da operadora (100.10.2.190/10).
  • Alocação de IPs Dinâmicos: O servidor DHCP gerencia as concessões de endereços a partir do IP 192.168.0.100, reservando a faixa inicial para o Gateway e Servidores fixos.
  • Resolução e Navegação Web: As estações resolvem domínios locais e externos através do servidor DNS (192.168.0.12) e acessam serviços Web hospedados no servidor HTTP (192.168.0.11).
  • Comutação Centralizada: O Switch Cisco 2960-24TT gerencia a interconexão em Layer 2 através das portas FastEthernet e GigabitEthernet.

Tecnologias Utilizadas

  • Simulador: Cisco Packet Tracer
  • Ativos de Rede: Roteador Cisco 1941, Switch Cisco 2960-24TT
  • Protocolos de Rede: IPv4, DHCP, DNS, HTTP, Ethernet (802.3)
